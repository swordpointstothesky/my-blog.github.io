## 前言

作为一名程序员，我一直想拥有一套属于自己的**通用后台管理系统**模板。它可以用来：

- **接私活**：快速交付小项目，不用重复写用户管理、权限控制
- **找工作**：作为技术作品集，展示全栈开发能力
- **写博客**：记录开发过程中的踩坑与思考

这篇文章记录了我从零开始搭建这个系统的全过程。我希望它不仅是我的开发日志，也能为其他正在做类似事情的开发者提供一些参考。

---

## 一、技术选型

在开始之前，我花了些时间做技术选型。2026 年的前端和后端生态已经非常成熟，我最终选择了以下组合：

| 层级 | 技术 | 选择理由 |
| :--- | :--- | :--- |
| **后端** | .NET 10 LTS | 性能优秀、跨平台、生态成熟，且是长期支持版本 |
| **前端** | React 18 + TypeScript | 生态最庞大，求职认可度高，Vite 构建极快 |
| **UI 组件** | Shadcn/ui | 无头组件 + Tailwind CSS，完全可控，比 Ant Design 更现代 |
| **数据库** | PostgreSQL | 功能强大，开源免费，支持 JSON 字段，方便扩展 |
| **ORM** | Entity Framework Core 10 | .NET 原生 ORM，Code-First 开发体验极佳 |

### 为什么不用 Vue？

我之前主要用 Vue 3，但这次决定挑战 React。原因很简单：**React 的生态和就业市场更广阔**。而且，把学习过程写成博客，本身也是一个很好的内容方向。

## 二、环境搭建：Monorepo 结构

我把前后端放在同一个 Git 仓库中（Monorepo 模式），方便原子化提交。

### 1. 初始化仓库

```bash
mkdir general-admin && cd general-admin
git init
```

### 2. 创建 .NET 10 后端

```bash
dotnet new webapi -n GeneralAdmin.Backend -f net10.0 --output backend
cd backend
dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL --version 10.0.0
dotnet add package Microsoft.EntityFrameworkCore.Design --version 10.0.0
cd ..
```

### 3. 创建 React + TypeScript 前端

```bash
pnpm create vite frontend --template react-ts
cd frontend
pnpm install
pnpm add axios react-router-dom
```

### 4. .gitignore 配置

我踩过一个坑：忘记忽略 node_modules 和 .NET 的 bin/obj 目录，导致仓库体积暴增。正确的 .gitignore 应该包含：

```gitignore
# .NET 编译产物
**/bin/
**/obj/
**/publish/

# Node 依赖
**/node_modules/
**/dist/

# 本地配置（包含密码）
**/appsettings.Development.json
*.env.local
```

## 三、前后端联调：第一个 Hello World

### 1. 后端写一个测试接口

在 Program.cs 中添加 CORS 和测试接口：

```csharp
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowAll", policy =>
    {
        policy.AllowAnyOrigin().AllowAnyMethod().AllowAnyHeader();
    });
});

app.UseCors("AllowAll");
app.MapGet("/api/hello", () => new { 
    Message = "Hello from .NET 10!", 
    Timestamp = DateTime.Now 
});
```

### 2. 配置 Vite 代理

在 vite.config.ts 中配置代理，解决开发环境跨域问题：

```typescript
server: {
    proxy: {
        '/api': {
            target: 'https://localhost:5001',
            changeOrigin: true,
            secure: false,
        }
    }
}
```

### 3. 前端调用

```tsx
useEffect(() => {
    axios.get('/api/hello')
        .then(res => setMessage(res.data.message))
        .catch(err => setMessage('请求失败：' + err.message));
}, []);
```

当浏览器显示出 "Hello from .NET 10!" 时，我知道前后端连接已经打通了。

## 四、登录功能实现：JWT + 路由守卫

### 1. 安装 Shadcn/ui 组件

在 Windows 上安装 Shadcn/ui 时，我遇到了一些坑（比如 tailwindcss init 命令找不到）。最终我用手动创建配置文件的方式解决：

tailwind.config.js

```javascript
export default {
    darkMode: ["class"],
    content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"],
    theme: { extend: {} },
    plugins: [],
}
```

postcss.config.js

```javascript
export default {
    plugins: {
        '@tailwindcss/postcss': {},
        autoprefixer: {},
    },
}
```

然后用以下命令初始化：

```bash
npx shadcn@latest init
```

### 2. 登录页组件

```tsx
// src/pages/Login.tsx
export default function Login() {
    const [username, setUsername] = useState('');
    const [password, setPassword] = useState('');
    const navigate = useNavigate();

    const handleSubmit = async (e: React.FormEvent) => {
        e.preventDefault();
        try {
            const res = await axios.post('/api/auth/login', { username, password });
            localStorage.setItem('token', res.data.token);
            navigate('/dashboard');
        } catch (err) {
            setError('用户名或密码错误');
        }
    };

    // ... 渲染 Shadcn 表单组件
}
```

### 3. 路由守卫

```tsx
function PrivateRoute({ children }: { children: JSX.Element }) {
    const token = localStorage.getItem('token');
    return token ? children : <Navigate to="/login" replace />;
}
```

### 4. 后端 JWT 登录接口

安装 JWT 相关包：

```bash
dotnet add package System.IdentityModel.Tokens.Jwt
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer
```

然后在 AuthController.cs 中实现登录和 Token 颁发。

## 五、接入 PostgreSQL

### 1. Windows 安装 PostgreSQL（zip 版）

我下载了 postgresql-18.6-1-windows-x64-binaries.zip，解压到 C:\pgsql：

```bash
# 初始化数据库
initdb -D C:\pgsql\data

# 启动服务
pg_ctl -D C:\pgsql\data -l C:\pgsql\logfile start

# 设置密码并创建数据库
psql -U rml -d postgres
ALTER USER rml WITH PASSWORD '123456';
CREATE DATABASE generaladmin;
\q
```

### 2. .NET 连接 PostgreSQL

安装驱动并配置连接字符串：

```bash
dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL --version 10.0.0
```

appsettings.json 配置：

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=generaladmin;Username=rml;Password=123456"
  }
}
```

### 3. EF Core 迁移

创建 User 实体和 AppDbContext 后，执行迁移：

```bash
dotnet ef migrations add InitialCreate
dotnet ef database update
```

### 4. 种子数据：自动创建管理员账号

在 Program.cs 中添加种子逻辑，启动时自动创建 admin/123456：

```csharp
using (var scope = app.Services.CreateScope())
{
    var dbContext = scope.ServiceProvider.GetRequiredService<AppDbContext>();
    dbContext.Database.Migrate();
    
    if (!dbContext.Users.Any())
    {
        dbContext.Users.Add(new User
        {
            Username = "admin",
            PasswordHash = BCrypt.HashPassword("123456"),
            Email = "admin@example.com",
            IsActive = true
        });
        dbContext.SaveChanges();
        Console.WriteLine("✅ 已创建默认管理员账号: admin / 123456");
    }
}
```

## 六、踩坑记录

### 坑 1：Tailwind CSS v4 + PostCSS 报错

报错：It looks like you're trying to use 'tailwindcss' directly as a PostCSS plugin.

解决：安装 @tailwindcss/postcss 并修改 postcss.config.js：

```javascript
plugins: {
    '@tailwindcss/postcss': {},   // 替换掉 'tailwindcss'
    autoprefixer: {},
}
```

### 坑 2：Shadcn 组件生成到了根目录的 @ 文件夹

原因：vite.config.ts 中的 @ 别名指向了根目录而非 src。

解决：修改 vite.config.ts：

```typescript
alias: {
    '@': path.resolve(__dirname, './src'),  // 指向 src
}
```

### 坑 3：PostgreSQL 连接角色不存在

报错：致命错误: 角色 "postgres" 不存在

原因：initdb 时没有指定 -U 参数，默认使用 Windows 登录名。

解决：用 psql -U rml -d postgres 连接，或者重新初始化 initdb -D C:\pgsql\data -U postgres。
