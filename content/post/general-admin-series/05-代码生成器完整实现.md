## 一、整体设计

### 1.1 工作流程

```
用户在界面选择数据库表
    ↓
后端读取表结构（information_schema）
    ↓
用户在界面配置字段（显示名、是否列表显示、是否表单显示）
    ↓
Scriban 模板渲染生成：
    - 后端：Entity、DTO、IService、Service、Controller
    - 前端：React 列表页（完整 CRUD）
    ↓
打包成 ZIP 下载
```

### 1.2 技术选型

| 组件 | 技术 | 说明 |
| :--- | :--- | :--- |
| **表结构读取** | Dapper + information_schema | 原生 SQL，比 EF Core 元数据更直接 |

| **ZIP 打包** | System.IO.Compression | .NET 内置，零依赖 |
| **前端界面** | Shadcn Select + Checkbox | 复用现有组件 |

## 二、后端实现

### 2.1 读取数据库表结构

关键是读取 `information_schema` 元数据，包括表名、字段名、类型、是否可空、是否主键等。

```csharp
public async Task<TableInfoDto?> GetTableColumnsAsync(string tableName)
{
    using var conn = CreateConnection();

    var exists = await conn.ExecuteScalarAsync<int>(
        @"SELECT COUNT(*) FROM information_schema.tables 
          WHERE table_schema = 'public' AND table_name = @TableName",
        new { TableName = tableName });

    if (exists == 0) return null;

    const string sql = @"
        SELECT 
            c.column_name AS ColumnName,
            c.data_type AS DataType,
            c.is_nullable AS IsNullable,
            c.character_maximum_length AS MaxLength,
            CASE WHEN pk.column_name IS NOT NULL THEN TRUE ELSE FALSE END AS IsPrimaryKey
        FROM information_schema.columns c
        LEFT JOIN (
            SELECT kcu.column_name
            FROM information_schema.table_constraints tc
            JOIN information_schema.key_column_usage kcu
              ON tc.constraint_name = kcu.constraint_name
            WHERE tc.table_schema = 'public'
              AND tc.table_name = @TableName
              AND tc.constraint_type = 'PRIMARY KEY'
        ) pk ON c.column_name = pk.column_name
        WHERE c.table_schema = 'public' AND c.table_name = @TableName
        ORDER BY c.ordinal_position";

    var rawColumns = (await conn.QueryAsync<RawColumnInfo>(sql, new { TableName = tableName })).ToList();

    return new TableInfoDto
    {
        TableName = tableName,
        Columns = rawColumns.Select(c => new ColumnInfoDto
        {
            ColumnName = c.ColumnName,
            CamelName = char.ToLower(c.ColumnName[0]) + c.ColumnName.Substring(1),
            DataType = c.DataType,
            IsNullable = c.IsNullable == "YES",
            IsPrimaryKey = c.IsPrimaryKey,
            MaxLength = c.MaxLength,
            DisplayName = c.ColumnName,
            ShowInList = true,
            ShowInForm = true,
            CSharpType = MapToCSharpType(c.DataType, c.IsNullable == "YES"),
            TsType = MapToTsType(c.DataType)
        }).ToList()
    };
}
```

**踩坑 1**：一开始用 `dynamic` 接收 Dapper 结果，遇到 NULL 值会抛 `RuntimeBinderException`。**必须定义强类型** `RawColumnInfo`：

```csharp
public class RawColumnInfo
{
    public string ColumnName { get; set; } = string.Empty;
    public string DataType { get; set; } = string.Empty;
    public string IsNullable { get; set; } = string.Empty;
    public int? MaxLength { get; set; }
    public bool IsPrimaryKey { get; set; }
}
```

### 2.2 类型映射：PostgreSQL → C# / TypeScript

```csharp
private string MapToCSharpType(string dbType, bool isNullable)
{
    var type = dbType.ToLower() switch
    {
        "integer" or "int4" => "int",
        "bigint" or "int8" => "long",
        "numeric" or "decimal" => "decimal",
        "boolean" or "bool" => "bool",
        "timestamp with time zone" or "timestamptz" => "DateTime",
        "uuid" => "Guid",
        "text" or "character varying" => "string",
        _ => "string"
    };

    if (type == "string") return "string?";
    if (isNullable) return type + "?";
    return type;
}

private string MapToTsType(string dbType)
{
    return dbType.ToLower() switch
    {
        "integer" or "bigint" or "numeric" or "decimal" => "number",
        "boolean" or "bool" => "boolean",
        _ => "string"
    };
}
```

### 2.3 Scriban 模板引擎

Scriban 是一个轻量级的 .NET 模板引擎，语法类似 Liquid，性能极佳。

**关键陷阱**：Scriban 用 `{{ }}` 作为表达式标记，而 React/TSX 里也大量使用 `{{ }}`（对象字面量）。**必须把复杂的对象字面量抽成变量**，否则会解析错误。

**错误示例**（会报 `Invalid token found ,`）：

```scriban
<DataTable
    pagination={{
        page: pagination.page,
        pageSize: pagination.pageSize,
    }}
/>
```

**正确做法**：

```scriban
const tablePagination = {
    page: pagination.page,
    pageSize: pagination.pageSize,
};

<DataTable pagination={tablePagination} />
```

### 2.4 传参：用 ScriptObject 而不是匿名对象

**踩坑 2**：一开始用匿名对象传参：

```csharp
await template.RenderAsync(new { Model = request });
```

结果模板里访问 `Model.DisplayName` 时，Scriban 报错 `Cannot get the member Model.DisplayName for a null object`。

**解决方案**：改用 `ScriptObject` 显式传参。

```csharp
var scriptObject = new ScriptObject();
scriptObject["TableName"] = request.TableName;
scriptObject["ModuleName"] = request.ModuleName;
scriptObject["CamelName"] = camelName;
scriptObject["DisplayName"] = request.DisplayName;
scriptObject["PkName"] = pk.ColumnName;
scriptObject["PkType"] = pk.CSharpType;
scriptObject["PkCamelName"] = pkCamelName;
scriptObject["Columns"] = columnsList;
scriptObject["ListColumns"] = listColumns;
scriptObject["FormColumns"] = formColumns;
scriptObject["DefaultVisible"] = defaultVisible;

var context = new TemplateContext();
context.PushGlobal(scriptObject);

return await template.RenderAsync(context);
```

### 3.2 前端模板（1 个，但很复杂）

`ReactList.scriban` 生成完整的企业级列表页，包含：

- 查询表单（可折叠）
- 工具栏（新增、删除、导入、导出）
- 表格（序号、多选、排序、分页）
- 列设置（持久化到 localStorage）
- 新增/编辑弹窗
- 删除确认弹窗
- 全屏、刷新

### 3.3 模板语法示例

**Entity.scriban**：

```scriban
using System.ComponentModel.DataAnnotations;

namespace GeneralAdmin.Backend.Models;

/// <summary>
/// {{ DisplayName }}
/// </summary>
public class {{ ModuleName }}
{
{{~ for col in Columns ~}}
    /// <summary>
    /// {{ col.DisplayName }}
    /// </summary>
    public {{ col.CSharpType }} {{ col.ColumnName }} { get; set; }{{ if col.CSharpType == "string" || col.CSharpType == "string?" }} = string.Empty;{{ end }}
{{~ end ~}}
}
```

**关键语法**：
- `{{ 变量 }}` — 输出变量
- `{{~ for x in list ~}} ... {{~ end ~}}` — 循环（`~` 会去掉空白）
- `{{ if 条件 }} ... {{ end }}` — 条件
- `{{ col.CamelName }}` — 访问对象属性

### 3.4 需要排除的自动字段

表单字段应该排除 `CreateTime`、`UpdateTime` 等自动生成字段：

```csharp
var excludeFromForm = new[] { "CreateTime", "UpdateTime", "CreatedAt", "UpdatedAt" };
var formColumns = new ScriptArray();
foreach (var col in request.Columns.Where(c =>
    c.ShowInForm && !c.IsPrimaryKey && !excludeFromForm.Contains(c.ColumnName)))
{
    formColumns.Add(ToColumnScriptObject(col));
}
```

## 四、ZIP 打包

```csharp
public async Task<byte[]> GenerateCodeAsync(GenerateRequest request)
{
    var files = new Dictionary<string, string>();

    files[$"{request.ModuleName}.cs"] = await RenderTemplate("Entity", request);
    files[$"{request.ModuleName}Dto.cs"] = await RenderTemplate("Dto", request);
    files[$"I{request.ModuleName}Service.cs"] = await RenderTemplate("IService", request);
    files[$"{request.ModuleName}Service.cs"] = await RenderTemplate("Service", request);
    files[$"{request.ModuleName}Controller.cs"] = await RenderTemplate("Controller", request);
    files[$"{request.ModuleName}s.tsx"] = await RenderTemplate("ReactList", request);

    using var ms = new MemoryStream();
    using (var archive = new ZipArchive(ms, ZipArchiveMode.Create, true))
    {
        foreach (var (fileName, content) in files)
        {
            var entry = archive.CreateEntry(fileName, CompressionLevel.Fastest);
            await using var writer = new StreamWriter(entry.Open(), Encoding.UTF8);
            await writer.WriteAsync(content);
        }
    }

    return ms.ToArray();
}
```

**踩坑 3**：`Templates/*.scriban` 需要配置复制到输出目录，否则运行时找不到模板。在 `.csproj` 中添加：

```xml
<ItemGroup>
    <None Update="Templates\**\*.scriban">
        <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
    </None>
</ItemGroup>
```

### 5.3 一键下载

```tsx
const handleGenerate = async () => {
    setGenerating(true);
    try {
        const res = await api.post('/api/generator/generate', {
            tableName: selectedTable,
            moduleName,
            displayName,
            columns,
        }, { responseType: 'blob' });

        const url = window.URL.createObjectURL(new Blob([res.data]));
        const link = document.createElement('a');
        link.href = url;
        link.download = `${moduleName}_generated.zip`;
        link.click();
        window.URL.revokeObjectURL(url);
    } catch (err) {
        alert('生成失败');
    } finally {
        setGenerating(false);
    }
};
```

**踩坑 4**：Axios 默认把响应解析为 JSON，下载二进制文件必须加 `{ responseType: 'blob' }`，否则 ZIP 会损坏。

## 七、踩坑记录

### 坑 1：`string??` 双问号

**现象**：生成的 DTO 里出现 `public string?? Name { get; set; }`。

**原因**：`MapToCSharpType` 对字符串返回的是 `string?`，模板里又加了一个 `?`。

**解决**：模板中判断 CSharpType 是否已带 `?`：

```scriban
{{~ if col.CSharpType | string.ends_with "?" ~}}
    public {{ col.CSharpType }} {{ col.ColumnName }} { get; set; }
{{~ else ~}}
    public {{ col.CSharpType }}? {{ col.ColumnName }} { get; set; }
{{~ end ~}}
```

### 坑 2：Scriban 的 `string.camelcase` 不存在

**现象**：模板里用 `{{ PkName | string.camelcase }}` 报错。

**原因**：Scriban **没有** `camelcase` 函数。

**解决**：在 C# 端预计算好驼峰命名，用 `PkCamelName` 传给模板。

### 坑 3：React/TSX 里的 `{{ }}` 冲突

**现象**：`pagination={{ page: 1 }}` 报 `Invalid token found ,`。

**原因**：Scriban 把 `{{` 当作表达式开始符号。

**解决**：把对象字面量抽成独立变量。

### 坑 4：变量声明顺序

**现象**：`Cannot access 'filteredData' before initialization`。

**原因**：`tablePagination` 定义在 `filteredData` 之前，但引用了它。

**解决**：调整声明顺序，或者把依赖的变量提前。
